Das Tool liest den Text aus deiner PDF aus, erkennt häufige Schlüsselbegriffe und wählt wichtige Sätze aus. Daraus erstellt es eine übersichtliche Zusammenfassung mit Begriffen und Merksätzen.

Wichtig: Dies ist eine lokale, einfache Zusammenfassung – keine echte KI-Analyse. Prüfe den Lernzettel mit deiner PDF. Bei eingescannten PDFs ohne auswählbaren Text kann das Tool den Inhalt nicht erkennen (dafür wäre OCR nötig).
Deine PDF bleibt auf deinem Gerät und wird nicht auf einen Server hochgeladen.
